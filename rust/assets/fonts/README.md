# Outfit

Retained unchanged from the Google Fonts repository as the source of the Omuse splash wordmark.
The splash embeds outlined SVG artwork at weight 750. The canvas text engine also
loads this bundled font so editable Sugata templates render consistently when
Outfit is not installed on the host. The editor workspace continues to use its
Omarchy theme fonts.

- Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/outfit
- File: `Outfit[wght].ttf` (stored locally as `Outfit.ttf`)
- SHA-256: `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`
- Licence: [SIL Open Font License 1.1](../../licenses/Outfit-OFL-1.1.txt)

The wordmark is outlined with fontTools 4.59.2 from the weight-750 instance, with 14 font units of tightened tracking. The SVG has no runtime font dependency.
