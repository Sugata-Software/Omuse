# Omuse 0.10.0 release qualification

**Published and verified — 11 October 2026.** Linux and Windows validation,
package checks, local Linux installation and anonymous public download checks
have passed. [Omuse 0.10.0](https://github.com/Sugata-Software/Omuse/releases/tag/v0.10.0)
is available. Interactive Windows support and general photographic quality
remain separate.

## Compatibility and remaining limits

- Keep an editable `.omuse` master. New **SmoothV1** and **TextureV2** recipes
  require a reader that understands them; older releases may refuse the project.
  Rasterize a separate copy in the newer version for backward editing. Rolling
  back the app does not downgrade artwork.
- PSD exchange is a converted, bounded subset. Live text/vector/effect content
  becomes pixels on export; 16-bit RGB PSD/PSB import retains the merged image,
  not its original editable layer structure. Photoshop/Affinity visual
  acceptance remains open. See [exchange limits](psd-exchange.md).
- Texture removal remains experimental and opt-in. Real-photo checks showed
  visible seams and a case where Context performed better. Context stays the
  default; there is no universal quality or speed claim.
- Shape Builder, path geometry, snapping and repeat generation have explicit
  admission and work caps. Saved repeats are independent copies. SVG clipping,
  general isolated compositing and other unsupported semantics remain refused.
- Windows packages remain unsigned experimental. Automated Windows Server
  checks do not establish interactive Windows 10/11, mixed-DPI, accessibility,
  clean-machine or live-provider qualification.
- No new paid or live AI generation request is part of this release pass.
  Typed command and review-path tests do not establish model accuracy.

Detailed maintainer logs remain outside the public source checkout in evidence
set `omuse-0100-2026-10-11`. Public CI, manifests and links above identify the
redistributed artifacts; local evidence identifiers are not download links.
