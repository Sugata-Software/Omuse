# Omuse logo explorations

[View the four-concept board](omuse-logo-concepts.png).

These initial concept directions were generated with the built-in image-generation tool on 27 September 2026. The user selected **Muse**, then **04 Sculpted** from the [Muse variations](muse-variations.md), and requested a retro treatment inspired by their company Sugata. The current direction is [Sunset Muse](sugata-retro.md), with vector assets for the launcher and theme-coloured app header.

- **01 Aperture:** a circular mark connecting image creation, an O and aperture segments. Most immediately photographic.
- **02 Lyre:** a reduced Greek lyre connecting the name to the Muses and artistic creation. Strongest mythological reference.
- **03 Ribbon:** a folded O/M form with an asymmetric opening. Recommended for a compact, contemporary app identity.
- **04 Muse:** a profile silhouette in a circular mark. Strongest figurative character; simplify further before very small icon use.

Production files are [the transparent vector mark](omuse-mark.svg), [the desktop SVG](../../rust/assets/omuse.svg), [the 256px desktop PNG](../../rust/assets/omuse.png), and [the theme-coloured header glyph](../../rust/assets/studio-icons/omuse.svg). The concept boards and extraction are raster references; production assets use independent SVG paths with real transparent negative space.

## Generation prompt

Use case: logo-brand. Asset type: one carefully art-directed logo exploration board for a premium native Linux/Omarchy image editor named Omuse (Omarchy + the Muses). Create a single landscape board with exactly four equally sized quadrants, generously spaced. This is a serious design studio presentation: restrained, refined, futuristic through geometry, functional at small icon sizes. Each quadrant shows a DIFFERENT highly resolved vector-like flat symbol, the same beautifully spaced lowercase wordmark 'omuse', and a small numbered concept label. Exact labels: '01  Aperture', '02  Lyre', '03  Ribbon', '04  Muse'. Concept 01: a confident circular O with an abstract M formed in the negative space by a few aperture-like folded segments, no generic camera illustration. Concept 02: a reduced contemporary Greek lyre symbol whose outer arms subtly read as M, only two or three interior strokes, art and inspiration. Concept 03: a single bold folded ribbon forming an O/M monogram with a crisp asymmetric opening, no infinity symbol. Concept 04: a minimal geometric Muse profile in negative space inside a circular O, sophisticated and sculptural rather than detailed or ornamental. Each concept must be visually distinct and clearly readable. Alternate warm ivory and near-black graphite quadrant backgrounds; marks predominantly monochrome with restrained muted periwinkle or pale gold accents, no rainbow. Include tiny monochrome icon variants beneath each main wordmark to show small-size feasibility. Flat 2D logo artwork, precise clean edges, balanced optical weight, editorial typography and excellent negative space. No gradients, no glow, no metallic rendering, no 3D mockups, no device frames, no watermark, no additional slogans or text.
