# Omuse 0.2.1 — Safer AI image editing

**29 September 2026 · Arch Linux / Omarchy · Linux x86_64 source pre-release**

This patch strengthens object removal, replacement, background editing and
canvas expansion, fixes immediate keyboard Undo after local finishing, and adds
a practical user manual. Project formats and the Ask Omuse workflow are unchanged.

## Protect the artwork you want to keep

- AI edit masks protect locked clipped artwork even when it depends on an
  unlocked clipping base or hidden mask source. The base stays editable outside
  the protected contribution.
- Expand checks whether live blur, motion blur, noise or grain would change the
  original pixels after canvas growth. It refuses those changes before sending
  a request, with guidance to keep the canvas or explicitly flatten a duplicate.
  Pointwise, layer-local, inactive and actually unchanged adjustments still work.
- Selection-only changes can rebuild a saved same-session masked result.
  Artwork, document, project or session changes continue to block stale Keep.
  Generate and Expand ignore irrelevant selection changes.

## Keep review and refinement reliable

- Completed images and retained references survive a failed history write
  through review and follow-up staging. Discard works even when that history
  store is unavailable, without replacing a damaged index.
- Background refinement restores supported local shadow/reflection presets.
  Unsupported custom historical values do not silently replace current controls.
- A variation batch stops after an invalid, stale, unretained or unqualified
  candidate, preserving the warning and leaving unsent requests unsent.
- **Apply local finishing** and **Remove local finishing** return focus to the
  editor. **Ctrl+Z** immediately undoes the artwork transaction.

## Current limits

This remains a source pre-release, with no downloadable application binary
attached. Synthetic checks establish integration and bounded pixel integrity;
complex photographs need visual review. Claude/Grok and live multi-variation
cancellation need separate qualification. No direct API billing is enabled.
Clean-target installation, broader desktop/accessibility coverage and dependency
notice gates remain open. Stopping work cannot guarantee a provider refunds
allowance it has already used.
