# Omuse 0.7.0 — Photos and vectors, one studio

**2 October 2026 · Arch Linux / Omarchy · x86_64 source pre-release**

Omuse 0.7.0 brings editable vector work into the ordinary photo canvas. Pen,
Nodes and Move tools share the Layers inspector, while local Image Trace turns
bounded bitmap subjects into editable colour shapes and keeps the source image
available. Photo foundations add target-colour uniformity and scale-aware,
premultiplied sampling for high-quality transformed exports. Shared control
styling and clearer colour fields make these workflows consistent across the
studio.

This release is source-only. The normal installer builds from source on a
supported Arch/Omarchy x86_64 system; no downloadable application binaries are
attached. It is a pre-release and does not establish full Photoshop or
Illustrator parity, broad Linux portability, independent photographic quality,
or physical-device qualification.

## What's new

- Edit vector artwork directly on the main canvas. Draw and refine Bézier paths
  with `P`, edit anchors and handles with `A`, and pick or move objects with `V`.
  Rectangles, ellipses and multiple paths share one artwork layer, with ordering,
  visibility, fill, stroke and opacity controls in Layers.
- Keep draft vector changes reversible. `Ctrl+Z` and `Ctrl+Shift+Z` work inside
  the open canvas session; Done/Enter commits one document transaction and
  Cancel/Escape discards it. Valid work is kept when changing tools, layers or
  saving.
- Trace bitmap layers locally with Logo, Illustration and Photo art presets;
  Colour, Gray and B&W modes; detail, smoothing, corner, noise, threshold,
  resolution and point-budget controls; Source/Trace comparison; and retained
  originals. Kept traces remain editable, save their settings and can be
  retraced.
- Apply Target Colour Uniformity with a reference colour, hue range/falloff and
  independent hue, saturation and lightness strengths. Selection masks,
  opacity, retained precision and hidden transparent RGB remain supported.
- Exchange one bounded styled SVG path, including supported curves, compound
  holes and solid styles. Unsupported multi-object, text, gradient, image,
  clipping and external-resource content is refused explicitly.
- Use scale-aware premultiplied Lanczos sampling for high-quality transformed
  16-bit exports, with explicit Smooth and Nearest choices, mask-aware source
  taps, cancellation checks and destination preservation on interruption.
- Apply consistent 3-pixel control corners, live colour swatches, transparency
  indicators, invalid-hex feedback, compact inspector spacing and ellipsis for
  long labels across the editing, Create, AI and command interfaces.

## Compatibility and limits

Vector scenes use project format 11. Ordinary canvases continue to use format
10. Omuse 0.6.0 cannot open format-11 scenes or projects containing the new
Target Colour Uniformity recipe; use Save As to retain a compatible copy before
upgrading. Rasterize explicitly before pixel tools or destructive photo edits.

Image Trace creates bounded RGBA8 solid-colour approximations. It does not
recover editable text, gradients, lossless photographic detail or original
illustration structure. Scenes retain one derived display image; persistent
damaged-region caching, gradients, boolean construction, advanced strokes,
typography, vector PDF and broad multi-object SVG exchange remain future work.
High-quality export has documented footprint and scale limits, and the
encoded-sRGB HSL uniformity operation is not perceptual luminance matching or a
complete wide-gamut pipeline.

No new AI provider request or subscription qualification is part of 0.7.0.
Existing AI workflows retain their earlier source identities and limits.
