# Omuse 0.6.0 — More control over every edit

**1 October 2026 · Arch Linux / Omarchy · Linux x86_64 source pre-release**

Omuse 0.6.0 brings richer photo finishing and more direct editing controls,
with Photoshop/SVG import improvements and safer save/reload behaviour. The
normal app and curl installer select the qualified runtime below.

## New ways to finish a photo

- **Dither & halftone:** ten styles covering diffusion, Bayer, halftone,
  patterns and ASCII, with pixel size and colour controls. Preview before Apply;
  selections are respected and Dither preserves existing transparency.
- **Bloom into transparency**, **Vignette overlay** and **Local tonal contrast**
  add distinct finishing tools. Bloom spreads highlights into existing layer
  margins, Vignette can start on an empty layer, and Local Contrast adjusts
  spatial detail. Apply is one Undo step; Cancel preserves the original.
- **Camera Raw sampling:** pick neutral white balance or green/purple fringes,
  and drag directly on the image to target curves or mixer hue, saturation and
  luminance. Sampling accounts for the relevant stage of the current grade.
- **Compact-window finishing:** the artwork preview adapts to window height,
  keeping effect choices accessible with more room for controls.

These finishing tools and Camera Raw use **8-bit raster copies up to 16 MP**.
Keep retained RAW/16-bit originals and work on a converted duplicate. Camera Raw
grading remains full resolution within that limit; its samplers do not operate
on sensor RAW or HDR data. Bloom does not enlarge the source layer.

## More direct everyday editing

Text drafts now preview through the artwork renderer, including their masks and
effects. Select letters to change their colour; cancelling the picker restores
the previous styling. Numeric labels support dragging, fine movement with Shift,
exact typing and reset, with Escape rollback.

Raster Eraser and sampled Clone/Heal strokes now keep working when the
foreground colour is transparent.

Brush, fill and gradient edits can grow a mask beyond its original bitmap while
preserving placement and outside coverage. Expansion has a **16 MP interactive
limit**. The crop tool adds **3:4**, and selection outlines adapt to low zoom
without changing the selection itself.

Layer actions explain unavailable operations before execution. Merge refuses
artwork outside the canvas and layer pairs still used by other live masks.
The group destination chooser identifies locked, cyclic and unchanged choices.

## Bring in Photoshop and SVG artwork

**PSD and PSB:** import supported layers, groups, masks and blend modes from
**8-bit RGB** documents. Limits are **512 MiB per file**, **30,000 pixels per
side** and **100 million decoded layer/mask pixels**. Off-canvas pixels remain
intact; excessive artwork is refused. **CMYK, 16/32-bit Photoshop documents and
embedded ICC profiles remain unsupported.**

Simple horizontal Photoshop text with a uniform style becomes editable while
retaining its cached appearance. Converting untouched imported text to pixels
keeps that appearance; actually editing it uses Omuse's fonts and layout.
Unsupported text stays rasterized with an explanation in the import report.

**SVG and SVGZ:** Open/Import and single-file drops offer raster dimensions with
a locked aspect ratio. Changed source files require refreshed dimensions before
Apply. Startup and multiple-file imports use intrinsic dimensions. Imports
become **one raster layer**, with the original file preserved. Input is limited
to **16 MiB before and after decompression**, output to **25 MP** and **30,000
pixels per side**. External resources, scripts and animation are not imported.

## Find work again and save safely

**Ctrl+Alt+O** opens searchable recent canvases and collections. External project
changes reload an idle, clean document after stable checks; unsaved work gets
**Keep editing**, **Save a copy** or an explicit discard-and-reload decision.
Repeated saves queue the newest edits. Stale background work cannot replace a
newer document or close an unrelated editing draft.

## Project compatibility

Omuse now reads canvas formats **1–10** and writes **format 10**, including pages
inside collections. Unicode colour runs are validated when imported. New saves
continue to use **`.omuse`**; opening an older project does not rewrite it.

**Omuse 0.5.0 and earlier cannot read new format-10 saves.** Use **Save As** to
retain an older copy before saving with 0.6.0. Application rollback does not
downgrade project files. Collection schema version 2 remains separate from the
canvas format.
