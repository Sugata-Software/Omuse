# Omuse 0.1.0 — First public source release

**29 September 2026 · Arch Linux / Omarchy · Linux x86_64**

Omuse brings layered photo editing and editable content creation into a native
Linux studio. This first numbered release gathers the work already available
through our source installer. It is an early source release, marked as a
pre-release on GitHub while broader desktop and distribution checks continue.
The application and desktop launcher are both **Omuse**.

## Photo editing

- Layers, groups, opacity, masks, clipping stacks, blend modes, live adjustments
  and effects, with Undo and Redo.
- Brush, Pencil, Eraser, Fill, Gradient, Clone and Heal tools; selections,
  feather, expand/contract, crop, trim and local subject selection.
- Editable text, shapes, paths and vector masks. Move selected groups together
  with descendants and linked masks in one Undo step.
- Camera RAW import through LibRaw, plus Camera Raw Light/Color, Effects,
  Curve, Mixer, Grading, Detail, Optics, Geometry and Calibration controls.
- RGB histogram, hue/saturation vectorscope and clipping preview. Preview
  processing runs in the background and rejects stale results; artwork changes
  only when an adjustment is applied.
- Layered PSD import with a conversion report, plus PNG, JPEG, WebP and TIFF
  export, including documented retained 16-bit PNG/TIFF workflows.

## Keyboard and canvas

- **Ctrl+K** searches and runs 171 commands; 101 default shortcuts cover tools,
  adjustments, layers and editing actions.
- **Ctrl+Alt+K** records, clears and restores custom shortcuts. The
  [keyboard reference](https://github.com/Sugata-Software/Omuse/blob/main/docs/keyboard-shortcuts.md)
  includes commands and canvas gestures.
- Middle-button panning joins the Hand tool and Space-drag. Auto Select picks
  the frontmost visible layer, while selected groups and multiple selections
  retain their movement behavior.
- Eraser shares Brush smoothing and release catch-up. Font names load when
  first needed, and adding a guide remembers that guides should be visible.
- Controls follow the current Omarchy theme through `gpui-omarchy`.

## Create and export

- Editable multipage `.omuse` collections, brand colors and font pairs,
  reusable components, image frames and composition guides.
- 20 editable templates with 80 preset-size variants, CSV-driven designs and
  a searchable local asset library.
- Ordered raster and multipage PDF packs with captions, image descriptions
  and a manifest. Page/layer animation, transitions, audio and editable
  subtitles support bounded MP4/GIF exports through FFmpeg.
- An optional in-app assistant with explicit review, Keep and Undo. Live
  evidence covers selected Codex subscription operations on earlier candidates;
  Claude and Grok are not generally qualified, and direct API billing is disabled.

## Reliability

- Staged project saves, exports and recovery replacement protect existing
  destinations when an operation fails before publication.
- Region-based painting history and immutable snapshots preserve reversible
  edits. Group movement, masks, clipping and floating selections have dedicated
  regressions.
- Updates retain the executable and runtime assets together. Failed updates
  preserve the active installation; rollback restores the previous generation.

## Install or update

Run as your normal desktop user on Arch Linux or Omarchy:

```sh
curl -fsSL https://raw.githubusercontent.com/Sugata-Software/Omuse/main/install.sh | bash
```

Then open **Omuse** from the launcher. The first build needs about 12 GB of free
space and takes longer than a cached update. The installer uses official Arch
packages and verified runtime downloads; it does not invoke an AUR helper.

Run the same command to update. Use `~/.local/bin/omuse-manage rollback` to
return to the previous installation. Uninstall keeps projects, settings and
recovery data. See the [installation guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/install.md).

The command follows the current tested installer channel. This release's
source is pinned by tag **v0.1.0** to commit
[`9c99e50684afd0854c8094a139b43205a263c33d`](https://github.com/Sugata-Software/Omuse/commit/9c99e50684afd0854c8094a139b43205a263c33d).
GitHub's source archives contain source code, not a prebuilt application.

## Tested scope

- **808 application tests passed:** 336 library, 227 UI and 245 integration;
  four manual timing benchmarks were excluded.
- Editing and six-page PNG/PDF/MP4/GIF journeys passed. All 80 template variants
  preserved editable content and exact rendered pixels after save/reopen.
- Production passed 24 native checks on Wayland and 24 on XWayland; the installed
  main launcher passed 24 further Wayland checks. Light/dark Camera Raw layouts
  and complete rollback in both directions were checked.
- The runtime passed [GitHub Rust/installer validation](https://github.com/Sugata-Software/Omuse/actions/runs/36492555743).
  The public installer pin separately passed all 36 installer regressions.

Earlier real-photo, performance and live-provider receipts retain their original
candidate scope. These results do not establish universal device support or
competitive performance.

## Known limitations

Camera Raw compatibility processing is 8-bit and capped at 16 MP. Scopes show
sampled display RGB. White-balance/defringe sampling, targeted curve/mixer drags
and scaled interactive previews remain open. Group resizing/rotation and
broader independent RAW, PSD and `.comp` interchange checks also remain open.
Copy/Paste currently transfers pixels; preserving editable whole-layer bundles
is planned. Keyboard zoom uses relative increments, and interactive crop-ratio
controls remain future work.

New `.comp` saves use format 9 and require a compatible reader; Omuse reads
versions 1–9. Sharing a format number does not establish cross-app compatibility.

No downloadable binary bundle is qualified yet. Dependency notice gaps,
clean-machine installation, memory-pressure testing and broader physical
input/display coverage remain release work. Tablet qualification is deferred.
