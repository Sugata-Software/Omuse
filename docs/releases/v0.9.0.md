# Omuse 0.9.0 — Photo detail, precise control

**4 October 2026 · Linux / Omarchy source pre-release · unsigned experimental Windows**

Omuse 0.9 preserves photo detail while retouching and makes everyday controls
more direct: guide object removal with clean nearby texture, align to a
configurable grid, inspect masks and preview fonts on selected letters.

## Retouch and repair

- **Keep source detail.** Blur, Smudge and Liquify work on native pixels of
  scaled, rotated or flipped photo layers, preserving dimensions and placement.
  Soft selections constrain edits; mask retouch retains the bitmap's extent.
- **Set Blur radius independently.** **Radius px** accepts 0.25–128 canvas
  pixels. Brush size controls the painted area; radius controls the blur spread.
  Blur preserves source alpha.
- **Guide object removal.** Choose a clean sampling rectangle and preview
  controlled removal. The replacement grows inward from boundary context;
  selected target pixels are never donors. Apply retains an editable recipe.
  Missing donor context refuses the edit without committing a partial result.
- **Keep edits dependable.** Typed numbers survive focus changes. Repeated
  mouse-up positions do not truncate long strokes; excessive work and
  recoverable retouch-buffer failures leave the attempted edit unapplied.

## Align, inspect and style

- Configure major grid spacing and subdivisions in **Canvas → View & alignment**.
  Drawing and snapping share the setting. Hold Shift to bypass grid snapping;
  visible guides can still attract the pointer.
- Alt-click **MASK**, or search **Inspect layer mask**, for a temporary grayscale
  view. Return to the artwork before painting. Inspection adds no Undo step
  and does not change exports.
- Use **Ungroup folder** to retain children and placement in one Undo. It refuses
  folders whose own appearance, locks or clipping relationships cannot be
  preserved. **Ctrl+Shift+G** remains vector Ungroup.
- Select letters in the text editor, open **Font**, search installed families
  and preview with hover or arrow keys. Enter keeps the choice; Escape restores
  the original. With a caret, the font applies to subsequent typing. Long lists
  keep readable rows and compact text panels keep Apply/Cancel visible.

Follow the [illustrated editing guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/user-guide/retouch-and-controls.md)
for steps, shortcuts and examples.

## Compatibility and limits

Projects still use `.omuse` and container formats 10–14. New removal recipes
record **ContextualV1**; older recipes with no algorithm retain **Legacy**
behavior. **Omuse 0.8 can display the cached result, but editing or resaving a
new recipe there can lose its algorithm choice.** Keep the 0.9 original and
rasterize a separate copy in 0.9 before backward editing.

Direct retouch requires an **8-bit raster layer or an existing mask**, limited
to **16 MP**, a **256 MiB working-buffer budget** and bounded stroke work. Keep
RAW/16-bit originals. Strokes compute on release; Escape does not interrupt
that calculation. Controlled removal has a separate **4-million-pixel** source
limit and needs useful nearby texture. The reviewed portrait improves but
retains some seam/texture mismatch; use Clone or reviewed AI reconstruction
when local texture is unsuitable.

Grid settings use presets, font search shows up to 64 installed matches, and
mask inspection is read-only. Windows remains unsigned experimental;
interactive Windows, live Windows AI, clean-machine, mixed-DPI/accessibility,
signing and broader hardware/photo-quality checks remain separate work.

## Install

On **Arch/Omarchy x86_64**, the source installer builds the tested revision:

```sh
curl -fsSL https://raw.githubusercontent.com/Sugata-Software/Omuse/main/install.sh | bash
```

Download application archives and checksums from this
[release page](https://github.com/Sugata-Software/Omuse/releases/tag/v0.9.0)
when attached. GitHub's automatic source archives are not installed apps.
For Windows, extract the complete ZIP and keep `lib`, `models` and `licenses`
beside `omuse.exe`. Retain the previous folder; Linux keeps its previous
complete installation for `omuse-manage rollback`.
