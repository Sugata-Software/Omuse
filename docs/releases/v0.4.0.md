# Omuse 0.4.0 — Your AI, a clearer studio

**30 September 2026 · Arch Linux / Omarchy · Linux x86_64 source pre-release**

This release brings the latest AI connection fixes, provider selection and
multi-step creation into the normal Omuse application, alongside a redesigned
right-hand workspace. Existing projects remain compatible.

## Choose the assistant for the job

Open **Ask Omuse → Connections** to check your existing subscription login.
Omuse now resolves Omarchy's mise-managed Codex and Claude executables
correctly when launched from the desktop, fixing the false **Unverified**
state caused by those shims.

Each of the eight tasks can use **Auto** or a provider you select. Choose
preferred Assistant and Images connections, exclude a connection from Auto,
and inspect the selected route before submitting. A pinned provider never
silently changes after an error. Separate API billing remains disabled.

Claude supports text-based design and editable layout proposals. Codex provides
the visual Photo/Caption and image task paths. An installed or signed-in
connection still needs the relevant capability check; it does not establish
access to every operation. See [connecting AI](https://github.com/Sugata-Software/Omuse/blob/main/docs/user-guide/README.md#ai-is-optional)
and [provider selection](https://github.com/Sugata-Software/Omuse/blob/main/docs/ai-provider-routing.md).

## Turn a brief into an image, layout and caption

An image generation or edit request can optionally continue with editable
layout and then caption/alt text. Omuse shows up to three subscription requests
before starting, holds the selected providers fixed and presents one final
review. **Keep** creates one undoable artwork transaction.

Stop, Local-only, a changed source document or an invalid step prevents
remaining requests from being sent. Saved reviews retain generated layer
identities so later layout edits can find the right image. The original artwork
stays unchanged until you review and keep a valid result.

## A clearer editing workspace

- Layers, Develop, Select and Canvas share aligned tabs and grouped controls.
- Create has six equal tabs in two rows, labeled fields and grouped exports.
- Ask Omuse uses a two-column task grid and a compact composer in short windows.
- Connections has a full-height view; Back retains the brief and result, and
  Stop remains available while a request is active.
- Disabled actions, active mask/clipping controls and keyboard focus have
  clearer states. Colours and styling follow the active Omarchy theme.

Read the [panel guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/inspector-panels.md).

## Install or update

Run the same command as your normal desktop user:

```sh
curl -fsSL https://raw.githubusercontent.com/Sugata-Software/Omuse/main/install.sh | bash
```

Open **Omuse** after installation. Existing windows keep their running version;
save your work and reopen to use the update. The installer retains the previous
complete app and assets for `~/.local/bin/omuse-manage rollback`.

This is a source release: the first installation compiles locally. No application
binaries are attached. There is one Omuse app, without a separate Preview launcher.

each passed **24 native checks**. Complete installation rollback passed in

retain their original candidate identities. They do not qualify every prompt,
provider or multi-step result. Grok remains unqualified; Claude image input is
not supported. Clean-machine installation, broader display/accessibility tests,
