# Omuse 0.2.0 — Ask Omuse, rebuilt around creative tasks

**29 September 2026 · Arch Linux / Omarchy · Linux x86_64 source pre-release**

Omuse 0.2.0 turns Ask Omuse into a task-based creative workflow. Choose a
task, customise a starter or write a brief, review the proposed result, then
Keep it as one undoable edit. Choosing a task or starter never sends a request;
the primary button and **Ctrl+Enter** submit the selected task.

## Create with Ask Omuse

- Choose **Design & layout**, **Enhance photo**, **Caption & alt text**,
  **Generate image**, **Replace selection**, **Remove object**,
  **New background** or **Expand canvas** from one task panel.
- See the target, provider and request context before submission. Design
  requests can include or exclude a canvas preview; visual photo and caption
  work uses the qualified visual-assistant route.
- Compare **Before** and **After**, inspect native plan changes, copy a caption
  or image description, and Keep a valid result only while its source canvas
  still matches.
- Use **Refine this result** or **Another direction** to continue from a saved
  proposal. The task, prior result and retained plus newly chosen references
  follow the next editable brief without submitting automatically.
- Stop active work and unsent variations. Unknown provider outcomes are not
  retried automatically, and generation does not alter the canvas.

## Editable photo and caption results

Photo enhancement adds clipped, editable **Exposure**, **Curves** and
**Hue/Saturation** layers to the active photo. Exposure is limited to ±3 stops;
brightness, contrast and saturation are limited to ±100%. Omuse rejects locked,
advanced, already-clipped and non-pixel targets before sending the request.
Original pixels, geometry, masks and other layers stay intact, and Keep is one
Undo step.

The review describes target layers by readable names while preserving exact
IDs inside the validated plan. Duplicate, unnamed and missing layer references
remain distinguishable without rewriting user caption text.

Caption tasks return one non-empty caption and one non-empty image description;
they cannot edit artwork. Photo tasks cannot target another layer or return
layout operations. Empty or invalid task responses do not expose **Keep** and
do not qualify a provider operation.

## Subscription and provider reliability

- Connections use official local subscription runtimes. Omuse does not select
  a separately billed API, store provider passwords or consume usage-reset
  credits.
- Provider discovery overlaps bounded probes and supports cancellation. Codex
  allowance and reset windows appear only when its official runtime reports
  them; missing information remains unavailable.
- Codex event handling retains valid early results while failing closed on
  forbidden operations and unexpected workspace instructions.
- Claude account and subscription evidence must agree before that route is
  trusted. Unsupported reference or visual routes are blocked before launch.
- Local-only collections still prevent remote submission.

## Safer review history

Completed proposals retain bounded plans, results, references and provenance
for later review. Concurrent windows merge current on-disk history under a
lock, and the new index is published before old artifacts are pruned.
Changed-canvas and previous-session results remain inspectable without being
allowed to overwrite current artwork.

## Current limits

- Visual photo assessment and caption drafting currently use **ChatGPT via
  Codex**. Claude and Grok are not live-qualified for the 0.2.0 visual workflow.
- Direct API billing remains disabled. Submitted requests may consume the
  selected provider subscription allowance.
- The live examples are synthetic. They do not establish photographic taste,
  arbitrary caption accuracy, every prompt or universal image quality.
- Photo enhancement affects the whole active ordinary pixel layer. It does not
  turn a selection into a local adjustment mask. Camera Raw temperature, tint,
  highlight and shadow controls are not exposed through this operation.
- Generation, replacement, removal, background and expansion retain their
  separately recorded capability evidence; this release does not newly
  qualify the complete image-operation set.
- This is a source pre-release. No downloadable application binary is
  qualified. Clean-machine installation, broader hardware/portability,
  memory-pressure and physical-input/display checks retain separate gates.
