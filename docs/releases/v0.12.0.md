# Omuse 0.12.0 — Precision, kept editable

**25 October 2026 · Linux / Omarchy pre-release · unsigned experimental Windows**

Public runtime: [`9c684cae4a4ccdb763d036b65adc440cc61419c2`](https://github.com/Sugata-Software/Omuse/commit/9c684cae4a4ccdb763d036b65adc440cc61419c2).
The [qualification record](https://github.com/Sugata-Software/Omuse/blob/main/docs/release-0120-qualification.md)
records exact-source tests, package checks and subsequent download/installer
publication. GitHub's automatic source archives contain source, not an installed application.

Work directly on vector artwork, inspect repairs at layer pixels, develop
retained 16-bit photos and keep the result editable in `.omuse`. Omuse 0.12
brings these controls into the shared canvas, layers, keyboard workflow and
reversible review experience.

## Work directly on your artwork

- Move linear/radial gradient endpoints, focus, radius and colour stops on the
  canvas, with synchronized inspector controls.
- Double-click into nested groups, edit within that scope and use breadcrumbs
  or Escape to step out. Surrounding artwork dims only for editing; its saved
  opacity does not change.
- Repeat a completed transform or transform editable copies. Add configurable
  stars/polygons, and swap solid vector fill/stroke with **X**. Copies remain
  independent objects; they are not persistent live instances.
- Keep clipping silhouettes and their complete contents editable. **Edit mask**
  selects the silhouette; **Edit contents** selects the retained artwork inside.
  Explicit mask rows select only the mask. Escape cancels the active gesture
  while preserving earlier edits.
- Inspect structured SVG/PDF compatibility reports and retain accepted SVG
  import notes with the artwork. Closing a report preserves the vector draft.

Clipping supports bounded closed-path silhouettes, including compound holes.
Nested clips and live-text masks remain unsupported. SVG/PDF export reports
conversions; it does not promise complete Illustrator, arbitrary SVG or editable
PDF/EPS interchange. Follow the [direct vector guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/user-guide/vector-controls.md).

## Inspect object removal before keeping it

**Controlled content-aware removal** now offers paired **Fit / 100%** source and
result views. Detail shows native image-layer pixels, rather than enlarging a
thumbnail. Fit/100%, four pan arrows, Center and Refresh stay pinned while the
images scroll on smaller windows.

A settings change invalidates the old review. Refresh during work replaces the
obsolete request, and Apply cannot keep a stale result. The source remains
retained and the accepted edit uses the existing Undo transaction. Frozen pixels
also remain protected during byte-warp operations.

Choose donors carefully and inspect seams, repeated texture and thin edges.
Context can refuse an object without enough allowed donor context; **Texture**
remains experimental. Difficult backgrounds, fabrics and thin edges need judgement. A plausible
repair is not evidence of what was behind an object. See [object removal](https://github.com/Sugata-Software/Omuse/blob/main/docs/user-guide/remove-objects.md).

## Keep photo precision and portable looks

Retained RAW/16-bit image layers can use the versioned **Native16** Camera Raw
path. Supported basic, curve, colour, detail, optics and geometry stages operate
on retained words, with guarded background review, native sampling, conservative
memory admission and one-step Undo. Older byte-compatible recipes keep their
existing interpretation.

This operates on already-developed RGB in encoded sRGB, linear sRGB or Display
P3, not sensor-linear RAW. Work is bounded to 16,777,216 pixels with additional
admission limits; large sources, histories and collections can be refused.
Scopes use display proxies. No calibrated camera/lens, HDR, Adobe appearance or
GPU-acceleration guarantee follows from this path.

Import a **Colour look (.cube)** into the editable photo stack and set Amount
from **0–200%**. Supported 1D, 3D and declared shaper-plus-3D tables stay embedded
in the project, so moving the original file does not break the look. Lookup
coordinates and output are clipped under explicit encoded-sRGB semantics. These
are creative looks, not camera/display profiles or HDR transforms. Input is
bounded to 16 MiB, 4,096 1D/shaper entries and 65 entries per 3D axis; project
budgets can impose additional limits.

**Import XMP preset…** reviews a bounded subset of preset intent before changing
Camera Raw's draft. The report separates supported approximations from
unsupported fields and stays with the kept recipe. Ordinary paint layers can
use **Promote to editable photo** first. Kelvin/As Shot white balance,
proprietary camera/lens profiles, crops and local adjustments are not imported.
Matching a slider name does not reproduce Adobe's rendering. Keep the original
XMP and project.

## Guide a local mask — experimental

Find **Guided subject mask** through **Ctrl+K**. An optional pinned EfficientSAM-Ti
CPU model accepts positive marks or one box, then offers up to three mask
options with source-cutout miniatures and a full canvas review. Processing stays
on the machine and does not consume an AI subscription or call a provider.

Download is explicit, about **40 MB**, with size/hash verification and retained
licence/provenance. **Verify / Repair** preserves the previous pack. EfficientSAM-Ti weights are
not bundled with the application. The application runtime is a separate
requirement; downloading weights cannot repair a missing runtime.

The model accepts at most six point tokens; a box uses two. Model-negative clicks
are not supported. Use **Brush add/remove**, with **[ / ]** for brush size, to
correct coverage. **Keep mask** adds an editable layer mask with one artwork
Undo; **Use as selection** records a selection Undo instead. Cancel/Escape
preserves the source and earlier selection. Keep requires the current reviewed
candidate, and consumes its prepared pixels rather than rendering it again.

This is editable guidance, not qualified matting. A prompt can select only part
of a subject; masks can leave holes or include unwanted background. Inspect every
result and refine manually. Scores under Details rank suggestions and are not
calibrated confidence or cutout quality. See the [illustrated editor guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/user-guide/editor-quality.md).

## Finish gradients, paths, text and shortcuts

- **Classic** gradients preserve existing behavior. Opt-in **Perceptual** uses
  OKLab; deterministic fill **Dither** reduces visible banding. Original stops
  remain editable in `.omuse`. SVG/PDF expands perceptual curves into bounded
  stops; dithered objects become bounded pixel artwork, including their stroke.
  Other objects remain vector. Read the conversion report before sharing.
- Review **Simplify** against retained originals, preserve corners and reset
  the preview. Repeated previews do not progressively simplify the last result.
- Enable optional **Tangent / Perpendicular** contacts for supported straight
  Pen segments. Ordinary anchors take precedence; Shift/Alt bypass contact
  snapping. These are bounded snapping aids, not general geometric constraints.
- Compare up to three installed fonts on your actual text, including Unicode
  and fallback information. Keep/Cancel preserves the existing text workflow
  and Undo. Samples are bounded; check real wrapping before keeping a font.
- Review the current owner of a shortcut before an atomic draft reassignment.
  Cancel preserves both bindings; reserved and stale assignments stay guarded.
- Preserve a narrow allowlist of inert SVG leaf-object labels/application
  metadata through editing and save/export. Script, event and external-resource
  restrictions remain; root/group/definition metadata is not fully retained.

## Save with a clear outcome

Press **Enter** in Open, Import, Save and Export path fields. Existing-project replacement still requires its explicit review; Enter never discards an unsaved-work prompt.

A complete package is staged before publication. If it is written but final
storage flush or saved identity cannot be confirmed, Omuse retains recovery,
dirty state and pending-close protection. Retry or save a separate copy; an
unknown destination identity never permits a blind overwrite. A dismissed
notice does not confirm durability or discard recovery.

Linux replacement preserves bounded visible ownership, modes, ACLs and extended
attributes, including Create page/component inheritance, while staging stays
private. Unconfirmed publication retains complete prior packages. These are
bounded filesystem/fault-tested policies, not a power-loss guarantee. Hidden
privileged attributes, inode flags, timestamps, different-principal behavior and
Windows ACLs remain outside that qualification. Keep backups.

## Project compatibility

**Save a separate `.omuse` master before using these retained features.** The
writer selects the highest required document version across the artwork:

| Retained feature | Minimum document format |
| --- | --- |
| Editable vector clipping, scene 5 | 16 |
| Embedded `.cube` looks | 17 |
| Perceptual/dithered paints or inert SVG application metadata, scene 6 | 18 |
| Native16 Camera Raw recipe nodes, including disabled/zero-opacity nodes | 19 |

Omuse 0.11.0 and older cannot read these newer projects. Ordinary retained
16-bit sources alone still use format 10, and older recipes keep their defaults;
not every save is upgraded. Releasing a clip does not guarantee downgrading an
already upgraded scene. Rolling back the app does not convert a project.
Keep the new master and export a separate rasterized copy (PNG/TIFF) for older workflows.
Create collections remain version 2 and retain each page's document requirements.
See [project formats](https://github.com/Sugata-Software/Omuse/blob/main/docs/project-format.md).

## Installation and qualification

The usual Arch/Omarchy source installer is:

```sh
curl -fsSL https://raw.githubusercontent.com/Sugata-Software/Omuse/main/install.sh | bash
```

The source installer selects the exact tested runtime above. Run the same command
to update. Updates retain the previous complete application and runtime assets;
`~/.local/bin/omuse-manage rollback` switches application generations but does
not convert newer projects. Keep separate compatible masters and exchange copies.

Review the [download guide](https://github.com/Sugata-Software/Omuse/blob/main/docs/downloadable-releases.md)
for versioned Linux/Windows archives, checksums and the unsigned Windows setup
wizard. The release page lists assets only after their explicit verified
publication. A source tag alone does not establish a downloadable application.
Exact-source Linux/Windows validation is [run 40161067985](https://github.com/Sugata-Software/Omuse/actions/runs/40161067985);
the package build is [40161068022](https://github.com/Sugata-Software/Omuse/actions/runs/40161068022).
The [release qualification](https://github.com/Sugata-Software/Omuse/blob/main/docs/release-0120-qualification.md)
keeps final package, native, installation and public-readback evidence separate.

Physical input/backend coverage, broader hardware/Windows interaction, general
photo reconstruction/matting and broad print/editor interchange remain bounded.
No new live-provider or subscription entitlement is established by this release.
