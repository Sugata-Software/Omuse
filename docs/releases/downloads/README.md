# Reviewed download manifests

This directory is reserved for generated, reviewed `vX.Y.Z.json` download
declarations. No version is selected automatically. Copy the exact canonical
candidate manifest from a completed **Omuse downloadable preview builds** run
and follow [the versioned-download workflow](../../downloadable-releases.md).

Each declaration binds both native archives to the exact source and successful
build attempt. Published declarations and their assets are immutable; use a new
version for corrections. A checked-in declaration alone does not mean that its
downloads have been published successfully.
