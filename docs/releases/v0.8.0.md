# Omuse 0.8.0 — Colour, curves and control

**Release candidate · publication pending · Linux / Omarchy and experimental Windows**

Omuse 0.8.0 brings reference-colour matching, curved lettering and shape
construction to the shared photo and vector studio, alongside softer masks,
more consistent retouch strokes and closer inspection of JPEG exports.

## Photo editing and safer masks

- **Match reference colour** adds an editable Filter-stack recipe with Amount,
  Preserve lightness and optional masking. It supports 8-bit and retained
  16-bit sRGB/Display P3 sources and remains usable after the reference moves.
- **Hue range** adds sampled hue, softness and saturation protection. Create,
  add, subtract or intersect a selection, or replace a layer mask. Combined
  previews show the chosen result and refuse stale underlying selections.
- **Preserve soft edges** in reveal/hide and editable filter masks on
  transformed layers. New group/adjustment masks retain their canvas extent
  without moving children; Photoshop masks retain their outside coverage.
- **Refine retouch strokes.** Blur, Smudge and Liquify gain fractional brush
  footprints and consistent spacing. Smudge carries paint; Liquify samples the
  original stroke source. Work limits reject excessive strokes without partial edits.
- **Inspect encoded JPEG pixels** at Fit or 100%, with drag/arrow panning and
  quality, DPI and matte controls that fit the minimum supported window.
- **Undo immediately after Apply.** Camera Raw and subject refinement restore
  editor keyboard focus when the result commits. Masked 16-bit edits also
  preserve exact rounding for unchanged alpha, including translucent pixels.
- **Improve imported artwork.** PSD import corrects Levels gamma and separates
  master HSL from Colorize, reporting unsupported bands and mapping differences.
  External project font/colour runs import without rerendering cached artwork.

## Vector artwork on the same canvas

- Select multiple objects; move, duplicate, group, align, distribute, rotate
  and scale them in Layers, preserving nested groups and editable children.
- Combine filled shapes with **Unite, Subtract, Intersect, Exclude and Divide**.
  Results use polygonal paths; Undo restores the original curves.
- Create **linear/radial fills** with 2–16 colour/alpha stops and
  Pad/Repeat/Reflect spread. Set stroke caps, joins, dashes, offsets and miter limits.
- Put **editable text on a curve**, adjust its font/layout, update its guide
  explicitly, or use **Convert to outlines** for glyph-node editing. Outlining
  changes the selected object in place: duplicate it first to retain editable
  text. Undo restores the recipe. Saved outlines preserve appearance; later
  text edits reshape with local fonts and report the families actually used.
- Exchange supported objects and styles through **SVG artwork**. Export
  **vector PDF** with curves, transparency, outlined text and Pad gradients.
  Existing destination files are preserved.
- Use **Ctrl+Y** for Outline view and **Ctrl+K** to find commands. Simple admitted
  documents gain editing previews up to 4× within the pixel budget.

## Project compatibility

Projects continue to use **`.omuse`**. File-format numbers describe saved
content, independently of the application version:

| Content | Canvas format |
| --- | --- |
| Ordinary canvases | 10 |
| Legacy flat vector scenes | 11 |
| Grouped vector scenes | 12 |
| Gradients and advanced strokes | 13 |
| Editable text on curves | 14 |

**Use Save As to work in a new copy before trying the new features.** Omuse
0.7.0 cannot open formats 12–14 or the new reference-colour operation. Removing
features does not automatically downgrade an upgraded scene. Save As preserves
the older original; it does not convert new semantics backwards. Linux and
Windows use the same formats.

## Install and experimental downloads

The existing one-command installer builds the qualified source revision on
**Arch/Omarchy x86_64**:

```sh
curl -fsSL https://raw.githubusercontent.com/Sugata-Software/Omuse/main/install.sh | bash
```

The installer advances only after qualification; these candidate notes leave
its current release selection unchanged.

Linux and Windows downloads use an **unsigned experimental** preview channel
with checksums and a reviewed manifest. Availability remains pending below.
For Windows, extract the complete ZIP and run `omuse.exe`, keeping `lib`,
`models` and `licenses` beside it. Retain the previous folder for rollback.

Windows source includes canvas/Create editing, recovery, optional RAW/subject
tools and Ask Omuse integration. Subject selection needs the Visual C++ runtime,
motion needs FFmpeg, and AI needs provider setup/sign-in. Package checks target
Ubuntu 24.04 and Windows Server 2025 x86_64. Live Windows AI, interactive Windows
10/11, mixed-DPI, physical hardware and broader Linux portability remain
unqualified by the checks described here.

## Limits to know

Reference matching transfers a global palette, without semantic or HDR look
matching. Range masks retain pixels rather than a hue-generation recipe.
Retouch remains raster work; preserve RAW/16-bit originals. JPEG previews and
references are limited to 16 MP; references also have a 128 MiB file limit.

Curved text accepts one line up to 512 characters, refusing unsupported glyphs
or a guide too short to fit. Vector PDF exports artwork only, with Pad
gradients. SVG text import, clipping/effects, variable-width strokes, mesh fills,
full Illustrator/PDF interchange and print-ready CMYK remain unsupported.

Photoshop import remains 8-bit RGB PSD/PSB; embedded ICC, 16/32-bit and CMYK
files are refused, and mixed-style text is not fully converted. These additions
do not establish full Photoshop/Illustrator parity or a complete high-precision
display pipeline.
