# Public media

## Current: Omuse 0.7.0 studio film

[`omuse-0.7.0-studio-film.mp4`](omuse-0.7.0-studio-film.mp4) is the two-minute
film featured in the README. It shows current production screenshots, four
photo comparisons re-exported through 0.7.0, six branded pages and native motion.
The poster is a frame decoded from the finished film.

See the [chapters, text companion and credits](omuse-0.7.0-studio-film.md),
[WebVTT captions](omuse-0.7.0-studio-film.vtt), and
[verification receipt](omuse-0.7.0-studio-film-receipt.json).
The original licensed Sunset Muse soundtrack is retained without re-encoding.

`omuse-0.7.0-photo-editor.png` is a fresh capture of the installed 0.7.0 editor
on an isolated copy of the mountain-lake project, with retained source pixels
and live exposure/colour-balance layers. Its photograph uses the credit below.

## Previous: Sunset Muse promo

`omuse-sunset-muse.mp4` is the previous two-minute Omuse promo film, retained
with its original credits. It is a web-ready, fast-start MP4 with H.264 video and stereo
AAC audio. `omuse-sunset-muse-poster.jpg` is a frame decoded from the finished
film at 61 seconds; it is not a separate mockup.

The film presents selected Omuse workflows. It is promotional media rather
than release-qualification evidence. See the
[complete media credits and licence record](omuse-sunset-muse-credits.md) for
the music, photographs, modifications and file hashes.

## Previous photo editor capture and photograph credit

`omuse-photo-editor.png` is an actual capture of the native Omuse app on
Omarchy, showing a retained source photograph with live exposure and colour
balance adjustment layers. The photograph was edited through Omuse's Rust
engine. This is an application capture, not a UI mockup.

Photograph: [Willian Justen de Vasconcellos — Reflection of Mountains on the Lake](https://www.pexels.com/photo/reflection-of-mountains-on-the-lake-23531520/),
used under the [Pexels licence](https://www.pexels.com/license/). The photograph
retains its own licence; it is not covered by the application's MIT licence.

The promo and capture are release media, not application runtime assets. The
application's MIT licence does not relicense the music or photographs.
